# Contribution examples / Ejemplos de aportes

These are **illustrative proposals**, not completed reviews or accepted contributions. Submit a source-backed proposal through the [private site form](https://cyberdeceptionatlas.org/es/contribute) or open a public issue or pull request in this repository when the content can safely be public. Report vulnerabilities through [GitHub's private security channel](https://github.com/fedequark/cyberdeception-atlas-community/security/advisories).

Estos son **ejemplos de propuestas**, no revisiones terminadas ni aportes aceptados. Enviá una propuesta con fuentes mediante el [formulario privado](https://cyberdeceptionatlas.org/es/contribute), o abrí un issue o pull request público si su contenido puede difundirse. Informá vulnerabilidades por el [canal privado de GitHub](https://github.com/fedequark/cyberdeception-atlas-community/security/advisories).

Every proposal should identify the record or resource, a primary source and a precise locator (version, section, page or commit), the proposed change, its evidence limit, and any relevant affiliation or interest. Choose whether and how you would like credit if the contribution is published; that preference is not a promise of authorship or publication. Do not paste credentials, live decoy details, personal telemetry, paywalled full text or restricted third-party material.

Cada propuesta debe identificar la ficha o el recurso, una fuente primaria y un localizador preciso (versión, sección, página o commit), el cambio solicitado, el límite de la evidencia y cualquier afiliación o interés pertinente. Indicá cómo querés figurar si se publica el aporte; esa preferencia no promete autoría ni publicación. No pegues credenciales, detalles de señuelos activos, telemetría personal, textos completos con acceso restringido ni material de terceros que no puedas redistribuir.

| Type / Tipo | Illustrative proposal / Propuesta ilustrativa | Evidence and acceptance / Evidencia y aceptación |
| --- | --- | --- |
| Correction / Corrección | “The summary of record `cowrie` appears to describe a feature absent from the cited release.” / “El resumen de `cowrie` parece describir una función ausente en la versión citada.” | Link the exact tagged release and documentation section; quote only a short necessary excerpt; propose replacement wording. A maintainer checks the source and records a reasoned revision. / Enlazar la versión y sección exactas; citar solo un fragmento breve; proponer texto de reemplazo. Un mantenedor verifica la fuente y registra una revisión motivada. |
| New record / Nueva ficha | “Please consider this defensive deception resource.” / “Sugiero incorporar este recurso de engaño defensivo.” | Provide the primary project or paper URL, version/date, resource kind and inclusion rationale; identify what was actually examined. A maintainer checks scope and duplicates before creating a draft. / Aportar URL primaria, versión/fecha, tipo y motivo de inclusión; aclarar qué material se examinó. El mantenedor verifica alcance y duplicados antes del borrador. |
| Paper review / Revisión de artículo | “I can review the methods and limits of this DOI.” / “Puedo revisar métodos y límites de este DOI.” | Supply DOI, accessible version, pages for design/results/limitations and a bounded synthesis; do not upload the article PDF unless its license permits it. Another authorized reviewer must assess the draft before delegated publication. / Dar DOI, versión accesible, páginas de método/resultados/límites y síntesis acotada; no subir el PDF sin licencia. Otro revisor autorizado debe evaluar el borrador antes de publicación delegada. |
| Software update / Actualización de herramienta | “Version X changed a documented capability.” / “La versión X cambió una capacidad documentada.” | Link release notes and the exact tagged code or documentation; state whether the change was only documented or tested. / Enlazar notas de versión y código o documentación etiquetados; distinguir lo documentado de lo probado. |
| Translation / Traducción | “This Spanish sentence overstates the English source.” / “Esta frase en español exagera la fuente inglesa.” | Identify record, original sentence, proposed translation and source passage; preserve uncertainty and vendor attribution. / Identificar ficha, frase original, traducción propuesta y pasaje fuente; conservar incertidumbre y atribución al proveedor. |
| Evaluation / Evaluación | “I propose a bounded HTTP-decoy pilot.” / “Propongo un piloto acotado de señuelo HTTP.” | Predefine environment, baseline, controls, repetitions, denominators, outcomes, failures and safety boundary; distinguish a functional check from operational effectiveness. / Predefinir entorno, referencia, controles, repeticiones, denominadores, resultados, fallos y límite de seguridad; distinguir prueba funcional de eficacia operativa. |
| Reproduction / Reproducción | “I will rerun the `v2026.10` archive on a clean environment.” / “Repetiré el archivo `v2026.10` en un entorno limpio.” | Record OS/tool versions, archive SHA-256, commands, expected and observed hashes and deviations. Call it independent reproduction only after a person outside the project actually runs and reports it. / Registrar versiones de sistema y herramientas, SHA-256, comandos, hashes esperados y observados y diferencias. Llamarla reproducción independiente solo cuando alguien externo la ejecute y documente. |

The owner currently handles decisions. Reviewer and publisher roles will be assigned only to people who accept them. An issue, form submission or pull request is a proposal until an editorial decision and a versioned publication occur.

El propietario toma las decisiones por ahora. Las funciones de revisor y publicador se asignarán solo a personas que las acepten. Un issue, formulario o pull request es una propuesta hasta que exista una decisión editorial y una publicación versionada.
