# Security reports

Report a vulnerability privately through the **Report a vulnerability** button under [Security advisories](https://github.com/fedequark/cyberdeception-atlas-community/security/advisories). Include the affected version, a minimal reproduction and the expected impact. Do not put credentials, personal data, live decoy locations or operational telemetry in a public issue or pull request.

The maintainer will triage the report and coordinate a fix and disclosure with the reporter. No guaranteed response time is claimed. Avoid testing production availability or accessing other people's records.
